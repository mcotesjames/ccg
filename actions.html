02

Status tabs

Segmented filter: the active tab fuses with the band below

Interaction notes
  • Click: the active plate flips white to deep green with lime text instantly; inactive tabs warm on hover, also instantly.
  • Anatomy: each tab pairs its label with a zero-padded count set smaller and lighter; tabs are divided by hairlines inside a hairline frame.
  • In context: the tab row sits flush against a deep green band so the active tab reads as one surface with the filtered content beneath it; switching resets dependent filters and pagination.
  • Responsive: below tablet width the row stretches full width with tabs sharing space equally; on mobile the padding tightens and the counts disappear.
03

Text filter

Lead-size filter tabs: gold underline marks the active choice

Scroll or drag the rows — switch viewport to see the overflow

Interaction notes
  • The frame above is a real viewport running the production component inside the wrappers the news archive and portfolio browser put around it. The gold dashed rule marks the content edge, so the row's behaviour at that edge is visible rather than guessed at.
  • Overflow: a set that outgrows its column scrolls horizontally within the row — the same treatment the service tabs use. Switch to the mobile viewport and drag the six-option row sideways; the three-option row above it fits and stays put.
  • Drag: a row that overflows can be dragged with the pointer, scrubbing 1:1. Touch and trackpads can already flick a scroll container; a mouse cannot, so this exists for mouse users and is skipped entirely on rows that fit.
  • Drag versus click: movement under 5px is still a click and selects the filter. Past that the gesture becomes a drag, the cursor turns to a closed hand, text selection is suppressed, and the click that follows the release is swallowed — so dragging a row never changes the filter by accident.
  • No scrollbar: the scrollbar is hidden on purpose, so the row reads as text rather than as a control. The options that run past the edge are the affordance: never let the last visible option end flush with the column, or the row looks complete when it is not.
  • Never centre this row. The row must stay left-aligned at every width. Centring an overflowing row overflows it at both ends, pushing the first options past the left edge where scrolling cannot reach them — and a scroll container cannot rescue what sits before its own origin.
  • Below tablet width: the filter row and the year dropdown stop sitting side by side and stack, the row aligning left and the dropdown stretching to full width.
  • Sizing: at the 402 design width the content column is 354px, which shows roughly three to four short labels before the row starts scrolling. That is a display limit, not a content limit — the set can run as long as it needs to.
  • Small variant: narrow enough that the portfolio's three-option facet clears mobile without scrolling.
04

Category pills

Rounded outline filter on dark grounds: active fills lime

Interaction notes
  • Click: toggles the pill on or off instantly; active pills fill lime with deep green text, and any number can be active at once.
  • Hover: inactive pills brighten; both outline and text step up towards white.
  • Anatomy: fully rounded (the only rounded element in the system), with small labels, tight gaps, wrapping to as many rows as needed.
  • Rule of use: the dark-ground category facet in a filter stack: status tabs pick the primary set and category pills refine it by any combination; changing any facet re-filters and resets pagination.

Interaction notes
  • Click trigger: the options panel slides down from behind the trigger over 0.25s on the house easing curve; the chevron flips in step and the options cascade in with a slight stagger.
  • Click option: the value swaps, the active row takes a gold rule and deep green ink, the panel closes and focus returns to the trigger.
  • Outside click / Escape: both close the panel; Escape also restores focus to the trigger.
  • Width rule: the options panel always matches the trigger width, however wide the trigger runs.
  • Variants: the options panel is always light, even on dark grounds; the light variant re-inks only the label and trigger, whose underline brightens to white on hover.
  • In stacked mobile filter bars the trigger stretches full width with the panel opening edge-to-edge beneath it.
